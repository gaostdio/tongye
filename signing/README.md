# 同页公开调试签名

2026-10-27，维护者明确要求将同页现有的 `debug.keystore` 上传至此公开仓库。

此文件含调试签名私钥，已公开，任何人都能下载并用它签署 APK。它不能再作为保密凭据，也不应当用于生产版本签名。如果其他应用共用这把密钥，它们的签名身份也会受到此次公开的影响。

## 用途

普通用户下载和安装 APK 不需要此文件。它用于接手开发者配置与原同页体验版一致的调试签名；包名、签名匹配且版本号符合升级条件时，才能覆盖已有安装并保留数据。

已核对证书 SHA-256 与 0.2.7 APK 的历史签名记录一致：

```text
442970906a708862e02e7bbd75b8eb5671c167529cca48b270892ca0cd36074a
```

当前应用构建脚本没有改动，也没有重新编译 APK。需要使用此签名时，应在所需项目内显式配置；不要覆盖开发电脑的全局 `.android/debug.keystore`，避免影响其他项目。

此前交接文档关于“不含签名私钥”的描述对应原始交接包。此目录是本次明确授权公开的例外，其他签名私钥仍不得提交。
