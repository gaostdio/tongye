# 0.2.1 删除功能验证

日期：2026-10-05。包名 `app.tongye.diary`，versionCode 4，versionName 0.2.1。安装包为 `deliverables/同页-0.2.1.apk`，桌面副本为 `同页安装包.apk`；摘要附在 APK 旁。保持原包名、签名和数据库版本，可覆盖安装。

## 变更

自己的日记、私密日记与共同手账的详情页增加明确的「删除」文字按钮及底部「删除这一页」操作栏。确认框显示标题，并说明本机删除、下一次互传删除的生效方式及不可撤销；取消不修改数据。保存删除结果成功后才退出详情，失败时保留确认界面供重试。TA 的个人页仍由作者管理。

删除自己的非私密页或任一共同页生成删除记录；私密删除只影响本机。删除作为空间封面的手账时清空封面引用。寄出提示和收件预览显示删除/撤回数量，避免只有删除记录的文件被误认为空文件。原始照片暂不物理清理，避免破坏其他页面对同一照片的引用。

## 检查结果

- `build.ps1 -Verify`：构建、单元测试及 Lint 通过。
- 19 项测试，0 失败、0 错误。新增三项覆盖私密删除不寄出及封面引用清理、另一人删除共同手账及重复删除包去重、个人页删除传播及旧内容不因新传输版本而恢复。
- Lint：0 错误、12 条既有警告。
- APK v2 签名验证通过，与上一版使用同一调试签名。

## 原生界面与互传

在独立 Android 15 `tongye_test` AVD 中，用 Alice / Bob 两个隔离安装测试，未改动用户手机数据：

1. 覆盖安装后打开已有 Alice 日记。顶部显示「删除」，底部显示「编辑这一页 / 删除这一页」。
2. 用底部入口打开确认框，取消后日记仍可查看；用顶部入口再次打开并确认删除，保存成功后回到列表并显示「已删除这一页」。
3. 强停并重新启动 Alice，已删除日记没有恢复。
4. Alice 寄出下一份文件，Bob 通过真实 FileProvider 授权打开。预览显示 0 篇日记、0 页手账、0 张新照片、1 页删除或撤回。
5. Bob 确认收下后，TA 的列表中对应日记消失，共同手账保留。
