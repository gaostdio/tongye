# 本地版验证记录

验证日期：2026-10-05（Asia/Shanghai）。测试对象为 `app.tongye.diary` 的 0.1.0 本地版。安装包位于 `deliverables/同页-0.1.0.apk`，SHA-256 附在同目录。

## Android 15 模拟器实际运行

使用独立 `tongye_test` AVD、480×960 屏幕和 Asia/Shanghai 时区，通过 ADB 与 UIAutomator 操作界面。

- 首次进入完成昵称、开始日期与示例初始化；重启进程后仍保留设置与示例。
- 首页在 2026-10-05 显示「520 天」。四个底部入口可以切换；相册与手账预览能打开详情。
- 从共享手账进入编辑，添加星星贴纸、拖动并保存；重启应用后，在详情可访问性树中仍能看到位于新位置的星星。
- 创建一篇私密测试日记并保存，私密列表可以显示标题与正文。
- 设置 PIN，正确 PIN 可以解锁。锁定状态只显示锁页；测试标题、正文未进入可访问性树。
- 回到系统桌面再返回应用后，私密空间重新锁定。代码同时在 `ON_PAUSE` 和 `ON_STOP` 清除解锁状态，覆盖快速切换。
- 使用系统照片选择器导入 PNG 测试图；照片实际复制到了应用内部 `files/photos/`，返回画布后可以保存。最终代码根据 MIME 类型保留图片扩展名。
- 通过系统文件保存界面导出 ZIP，解析 `diary.json` 验证只包含三篇共享示例日记，私密测试日记被排除。
- 包含导入照片的 ZIP 中，JSON 的相对路径能找到对应原图条目；照片原始字节与文件长度保留。
- 检查 AndroidRuntime 日志，未发现本应用崩溃。

`deliverables/screenshots/` 是实际模拟器截图；`deliverables/verification/` 是测试模拟器生成的备份，不是用户真实数据，也不是应用内置数据。
