# 0.2.4 非私密个人页评论验证

正式包名 `app.tongye.diary`，versionCode 7，versionName 0.2.4。正式 APK：`deliverables/同页-0.2.4.apk`。交付文件仅在项目 `deliverables/`，不再复制到桌面根目录。

## 用户要求与修改

用户要求除了共同页，对方所有非私密日记/手账也能评论。当前 `canComment` 对 PARTNER、SHARED 开放，对 PRIVATE 关闭；本人可在自己的非私密页回复。TA 的个人页正文、布局仍只读，没有编辑/删除入口，收藏保持本机独立。

不能直接允许读者把个人页整页发回：那会把评论和内容所有权混在一起。版本 2 文件在 manifest 新增 `commentUpdates`，读者只带自己的评论、页面 ID 和作者 UUID，不带 TA 的旧正文或照片。接收检查评论者为寄件人、所有者为收件人、ID 去重及原长度/数量边界；仅合入现有的本人非私密页，不复活已删页、不触碰私密页、不更新正文时间。作者回信包含作者页面与合并评论；接收作者页面时正文版本不变也会合并评论。收件预览显示个人页评论更新及追加说明。

写版本 2、读版本 1/2，版本 1 缺新字段时按空处理；旧 App 会拒绝版本 2、提示更新，避免静默丢掉评论。双方一起覆盖升级至 0.2.4 后再交换新版文件，旧互传文件可继续读。Room 仍为 2，迁移、配对身份、原 AES-GCM、照片校验、私密过滤、删除记录、增量确认不变。正文同时编辑的冲突规则未改，评论仍不可编辑/删除，每条最多 200 字、每页最多 2000 条。

## 构建与自动测试

`./build.ps1 -Verify` 成功，35 项 JVM 测试通过（ExchangeTest 28、ModelsTest 4、WorkspaceDocumentsTest 3），0 失败、0 错误。Lint 0 错误、12 条既有警告。构建隔离 `.peer` 测试包后，已重新不带测试参数构建正式 APK。

`apksigner verify --print-certs` 成功，证书 SHA-256 为 `442970906a708862e02e7bbd75b8eb5671c167529cca48b270892ca0cd36074a`，与旧正式包一致。APK SHA-256 为 `4395783d2aef72e066709eb3e6c881e370e17c8030137b230aebabc53eece4d2`。AAPT 核对包名为正式包名、版本 0.2.4 / 7、minSdk 26、targetSdk 36，无 INTERNET 权限。AAPT 对中文交付文件名的读取存在编码问题，改读 SHA 相同的 ASCII 文件名构建输出完成检查。

新增 6 项测试：

1. 对个人日记和个人手账发表评论，加密回传仅有评论、不带正文和照片；原正文和时间不变，作者归属正确；重复包去重、完整寄件、回信确认后的增量停止都正常，读者仍不可删除。
2. 作者修改正文并发表评论，读者在旧副本发表评论；双向交换后双方保留新正文与两条评论，评论顺序一致。
3. 正文时间未变化时，作者的回复仍能合入读者页面，保留读者已有评论。
4. 晚到评论不复活已删除页，不修改已转私密页，私密内容与评论不进入寄件。
5. 伪造评论所有者、评论者、重复评论更新页面，以及回传本人无权编辑的个人正文，均拒绝。
6. 人工构造真正没有 `commentUpdates` 字段的旧版本 1 加密 ZIP，新版成功读入。

旧权限测试改为允许个人页评论，同时继续拒绝修改 TA 个人正文和评论私密页。首次旧包测试试图把缺字段的旧对象交给新版 Kotlin copy，被非空参数保护拒绝；改用实际旧版 ZIP 结构构造兼容性输入后，全部测试通过。未为测试放宽协议验证。

## Android 15 两套隔离安装

使用此前创建的 `tongye_test` AVD，分别覆盖安装正式 App 与 `.peer` 测试 App，保留已有 Alice/Bob 虚构身份和数据，未连接用户手机。

1. Alice 打开 Bob 的个人日记 `B-page`，正文只读、没有编辑/删除按钮，出现评论区。发表 `Reply-on-Bobs-page`，保存后数量为 1。
2. Alice 经实际系统分享/FileProvider 把文件交给 `.peer` Bob；Bob 预览明确显示「1 页评论更新 · 1 条评论」，收下成功。文件同时包含先前未确认的其他共享更新，并非本次凭空构造的只有评论文件。
3. Bob 打开本人 `B-page`，看到 Alice 的评论，可继续管理自己的正文并发表 `Reply-from-Bob`。Bob 经分享发回，Alice 确认收下。
4. 强停重启正式 App，Alice 再开 TA 个人日记，仍显示 Alice/Bob 两条评论及时间，未出现编辑/删除入口。

截图在 `deliverables/screenshots/0.2.4/01-comment-on-partners-diary.png`、`02-owner-reply-after-restart.png`，已检查排版。双向同时修改、照片隔离与私密/删除保护由 JVM 真正加密往返测试验证；模拟器不是两台实体手机微信/QQ 已验证的证明。
