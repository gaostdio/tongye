# 0.2.7 界面美化检查

2026-10-10。正式包名 `app.tongye.diary`，versionCode 10，versionName 0.2.7。交付 `deliverables/同页-0.2.7.apk`，20,028,063 字节，SHA-256：`69a12cc94283bc3d10067cf4782e5f6621bfa120db7cef119daabfb5ea1339c1`。

## 展示变化

- 保留奶油纸色、鼠尾草 / 雾粉 / 雾蓝三种主题、四个底部入口、原有文字与操作流程。主题沿用旧字符串，旧资料可直接使用。
- `Design.kt` 增加不需要图片资源的书页线稿、轻渐变封面、主题色图标底块、细边框纸卡和计数条。空状态沿用书页意象，标题和分组增加小装饰。
- 首页展示非私密留存页、共同页与影像数量，三个空间改为入口卡片，便签增加信纸细节。统计由已有数据计算，不插入记录。公开列表和影像计数用 remember 缓存。收发按钮位于封面之后；封面压缩留白，长昵称最多展示两行并省略，资料里的完整昵称保留。
- 日记卡片保留照片 / 动图 / 视频封面，增加类型图标、多个影像数量、评论数、收藏图标与分隔。个人手账不再误标为共同手账。正文标题和摘要过长时省略，打开详情后仍完整显示。
- 相册改为相纸式双列卡片，展示标题和日期；回忆导航使用沿用筛选方式的横向主题标签。日记列表仍使用 LazyColumn / 可见项组成，不转换为全量页面组成。
- 详情正文增加纸张容器，媒体增加圆角；收藏、编辑、删除、共享回应和评论权限保持。编辑器与手账布局、缩放、笔迹及文件路径不变。
- 我的页面增加主题封面，设置行的值独立换行，保留 PIN 与导出流程。主题选择有色块和当前勾选。导出入口改名「导出数据与影像」，说明照片、动图、视频都进入同一 ZIP；默认私密选择和导出逻辑不改。
- 明确设置 Material 主题的容器颜色，使选中筛选和对话框随本应用配色，不回落到默认紫色。

## 原生界面检查

只使用自建 Android 15 `tongye_test` 模拟器，没有连接用户实体手机。覆盖安装正式 APK；安装前保存既有虚构数据库，升级启动后逐文档对比，身份、资料和每篇日记不变。

为视觉截图临时加入三个明确标为「示例」的页面、内置矢量湖景 / 咖啡画面、虚构昵称、日期和便签。它们只进入隔离模拟器，不写入交付 APK 的初始化逻辑；新用户仍不会自动得到示例。截图中出现的口令属于已有虚构测试配对，不是用户口令。截图不能作为实体手机或真实用户资料的证明。

检查首页、日记列表与卡片、详情、正文与媒体、回忆相册、我的、三个主题切换、主题对话框、收发页面、空间入口和便签。打开删除确认后取消；打开普通编辑器、滚动确认照片 / 动图 / 视频入口仍在，不保存更改。TA 的个人页只有收藏和评论，没有编辑或删除；已有评论和发表评论入口正常显示。

另将模拟器调整为 320 dp 宽、字体 1.3 倍，使用双方各 12 个汉字的昵称检查首页。发现长昵称撑高封面后修复成最多两行省略；滚动后寄件按钮、统计和导航仍可使用。原 384 dp 宽、字体 1.0 下收发按钮可在首页第一屏直接操作。首次昵称入口的空输入、按钮禁用与说明显示正常。

检查结束后恢复原虚构数据库及密度 / 字体设置，再启动新版并逐文档核对，全部一致；AndroidRuntime 错误日志没有同页崩溃，模拟器已关闭。测试快照和临时数据库不进入交接包。
