# 同页 · 两个人，写在同一页

这是 **0.2.7 的 GitHub 源码副本**，没有个人照片或卡通贴纸；保留普通贴纸、GIF / 视频、界面美化和本地交换。上传方式见 `GITHUB-UPLOAD.md`。此版本没有 0.2.9 新增的滑动翻阅。

原生 Android 情侣日记的本地交换版。不接入日记服务器，不用注册；双方各自记录，再用加密文件把愿意分享的生活寄给对方。

交给其他智能体继续开发时，先阅读根目录 `AGENTS.md` 与 `HANDOFF.md`。交接检查见 `docs/handoff-review.md`；交接 ZIP 带文件摘要清单，可用 `tools/verify_handoff.py` 校验。

## 安装与体验

源码构建后生成 `deliverables/同页-0.2.7.apk`，最低支持 Android 8.0；本源码包不附安装包。后续交付统一放在项目 `deliverables/`，不再复制到桌面根目录。首次进入只填写昵称并点击「开始记录」，也可点键盘的完成；再次打开直接进入主页。TA 的昵称和在一起日期可稍后在「我的」中设置，新用户不自动加入示例。

已安装旧版的手机可直接覆盖安装，保留现有日记、照片、昵称、日期和私密 PIN，不需要重新填写入口。请勿卸载旧版后安装。

**界面美化（0.2.7）**：保留奶油纸色、鼠尾草/雾粉/雾蓝三种主题、四个底部页面和原有功能；新增书页线稿、柔和封面、公开记录计数、三空间入口卡片、相纸式相册和更清晰的设置行。日记卡片显示媒体与评论数量，搜索框与「写一页」按钮更明确，详情正文与媒体增加纸张容器和圆角。首页计数排除私密页，装饰没有新权限、网络请求或用户数据。导出入口更名为「导出数据与影像」，仍导出相同 ZIP 数据、照片、动图和视频。

**动图与视频（0.2.6）**：普通日记点「添加照片、动图或视频」；手账点底部「图片/视频」。GIF 自动播放，视频点开后可暂停、继续和拖动进度；手账视频可拖动、缩放、旋转、移除。共同回忆相册也能看到视频封面。文件原样复制到本机，随加密回忆文件互传及 ZIP 备份；私密媒体不会寄出。双方一起覆盖升级至 **0.2.6** 再互传视频，不需要注册或接入云端。视频能否播放受手机支持的编码格式影响，常见 MP4 更合适；当前不提供拍摄、剪辑或转码。

**大量图片导出（自 0.2.5）**：「寄给 TA / 保存文件再发送」和「我的 → 导出数据与照片」逐张读取原图、直接写入文件，并显示处理进度，不再一次把所有照片装入内存。互传采用分段认证加密，移除旧 64 MiB 文件/128 MiB 解压限制；ZIP 备份先完整生成再写入所选位置。照片不缩小，内容相同的图片只打包一次。双方一起覆盖升级至 **0.2.5** 再寄新版文件；新版仍能接收旧文件。Android 隔离模拟器实测 120 张、120 MiB，自动测试验证 150 MiB 集合与 65 MiB 单图；容量仍受手机及保存位置的剩余空间影响。

**可以持续记录**：没有试用期限、使用天数限制或按时间清理日记的机制，也没有本机日记篇数配额。0.2.2 将旧版整行存储迁移为逐页、分段存储，避免全部日记增多后超过 SQLite 读取窗口；修改一页只写变更页及资料，并通过事务保存。日记、空间、回忆与便签历史列表按可见项显示，日记支持搜索标题、正文和日期。已用 10,000 篇数据验证旧库迁移，继续新增至 10,001 篇并重启核对；容量仍受手机空间和内存影响，这不是无限容量或永不丢失的承诺。

第一次，一人生成并复制口令发给 TA，TA 复制后点「粘贴并加入」。以后只需「寄给 TA」在微信/QQ 等选择对方，收到 `.couple` 文件后用同页打开并确认「收下这份回忆」。聊天应用不能直接打开时，先保存文件，再在同页点「收下 TA 的生活」选择文件。也提供「保存文件再发送」。

**删除日记或手账**：打开这一页，点右上角「删除」或底部「删除这一页」，确认后才删除。自己的记录与共同页可以删除；TA 的个人记录由 TA 管理。已分享页面的删除记录随下一份文件寄出，TA 确认收下后才从对方手机移除。私密页删除只影响本机。收件预览会显示删除或撤回数量。

**评论（自 0.2.4）**：共同页以及双方的非私密日记/手账都可以评论。打开页面，向下滑到「评论」，填写后点「发表评论」；自己页面也可回复 TA。每条最多 200 字，显示昵称和时间；旧留言保留。评论随下一份 `.couple` 寄出，TA 收下后可见。对 TA 个人页只追加评论，不能改正文、手账布局或删除该页；回传的是单独评论记录，不携带 TA 的旧正文和照片。双方各自发表评论会追加合并，重复收件不会重复显示。发表评论不修改正文的冲突时间；双方同时编辑共同正文仍按原有时间规则处理，尚无冲突副本。每页最多 2000 条评论，无评论编辑/删除入口；私密页不能评论。内部数据写版本 2、仍可读旧版本 1；视频采用内部数据版本 3，要求双方一起覆盖升级到 0.2.6。

1. **我们**：我的、TA 的、共同空间；收发回忆、恋爱天数、今日便签、便签历史、双方当天记录、最近日记、纪念日倒计时。
2. **日记**：我的、TA 的、共同、私密、收藏；创建普通日记或自由手账；修改、删除、心情、日期、喜欢和短留言。TA 的个人记录只读，共同页可轮流编辑。
3. **回忆**：相册、时间轴、手账集合、月度统计、纪念日。所有共同回忆只汇总共享内容。
4. **我的**：昵称、在一起日期、三种主题、私密 PIN、生物识别、ZIP 数据和原始照片导出、移除示例。

手账支持照片导入、文字框、内置贴纸、拖动、双指缩放与旋转、图层置顶、颜色和字号、八种纸张、四种可编辑模板、画笔、擦除上一笔、撤销和重做。模板会替换画布，可撤销。手账元素记录创建者和最后修改者。

## 当前版本的边界

- 各自的数据保存在各自手机里，通过加密文件主动交换，不实时同步。口令只需设置一次，只给 TA；无需云账号。旧示例仍标注「示例」，不会寄出。
- 互传包含非私密日记、照片、手账布局和笔迹、评论、共享回应、昵称、主题与 DIY 主页封面。私密页永不进入 .couple 文件。收到回信后按确认版本增量发送，已确认的照片不用重发；重复导入去重。
- 单次互传的 ZIP 及解压内容最多 8 GiB，每类 JSON 32 MiB，最多 20,000 页记录/删除记录及 5,000 个照片摘要；ZIP 备份没有上述互传大小限制。这些不限制本机继续写日记。生成与接收需要临时磁盘空间；超大文件尚不自动拆成多个附件，聊天应用也可能限制附件大小。已确认照片的增量回复不受历史确认摘要累计超过 5,000 个的阻断。
- 同一共同页的不同元素合并，同一元素按较新的时间处理，时间相同时按本机持久身份确定次序；删除保留撤回标记。文字和背景等属性按较新整页版本处理。
- 便签和额外纪念日当前只在本机；在一起日期未设置时可采用 TA 寄来的日期。尚未提供近距离自动发现、Wi-Fi Direct、独立主页编辑器和自定义图片贴纸。可把自己的非私密手账用作空间封面，随文件带给 TA。
- 私密锁属于应用内访问保护，Room 数据库未做内容加密。私密页面及收藏页防截图，进入后台后重新锁定；开启锁后，私密备份导出也需要验证。
- 照片通过系统选择器导入，并复制到应用内部。尚未实现相机入口、照片裁剪、透明度、自由擦除、图片去背景、字体切换、未来信、恢复备份与 PDF 回忆册。
- 「ZIP 备份」未加密，默认导出可分享内容，可明确选择加入本人私密页；不含互传口令或 PIN。与「寄给 TA」的加密 .couple 文件用途不同。
- 应用禁用系统云备份与设备迁移。卸载会删除应用数据；先导出备份。删除日记暂不清理原图文件，以避免其他日记引用的照片被删掉。
- 使用 Room 存储本机工作区，首次设置完成后再次打开直接进入主页。

## 开发与构建

Kotlin 2.1.20、Jetpack Compose、Material 3、ViewModel + StateFlow、Room 2.7.1、Coil、AndroidX Biometric。依赖版本固定；采用已验证的 AGP 8.11.1 / Gradle 8.14.3 / JDK 21 / Android SDK 36 组合。

在 Android Studio 中打开此目录，配置 SDK，执行 `assembleDebug`。命令行：

```powershell
.\build.ps1 -Verify
```

脚本优先使用当前电脑已有的 Codex Android runtime；其他电脑请设置 `JAVA_HOME`、`ANDROID_HOME` 并让 Android Studio 生成 `local.properties`，或运行 Gradle Wrapper。JDK 最低 17。

Windows 的 Gradle 测试进程在中文路径下出现过类加载错误，测试任务将受影响的 classpath 项复制到临时 ASCII 路径；源文件和 APK 仍在本项目里。日期和权限筛选有独立单元测试，`lintDebug` 检查 API 兼容性和 Compose 使用。

历史验证见 `docs/verification.md`、`docs/verification-0.2.0.md`、`docs/verification-0.2.1.md`，长期使用验证见 `docs/verification-0.2.2.md`；评论验证见 `docs/verification-0.2.3.md` 与 `docs/verification-0.2.4.md`，大量图片验证见 `docs/verification-0.2.5.md`，动图与视频见 `docs/verification-0.2.6.md`。当前界面与升级核对见 `docs/verification-0.2.7.md`，本次截图见 `deliverables/screenshots/0.2.7/`。Windows 验证脚本包含 48 项单元测试、Lint 和 96 MiB 内存下的 8 项流式测试，其他系统可运行 `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:streamingLowMemory`。新方案原文见 `docs/local-exchange-plan.md`，协议与使用说明见 `docs/local-exchange-guide.md`。
