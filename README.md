# 同页 · 两个人，写在同一页

> 有些日子很普通，却值得被两个人认真记住。

今天一起吃的晚饭，路边偶然发现的小店，一张拍糊了却舍不得删的合照，还有分别以后才想起来说的那句话。

**同页**是一款给两个人准备的原生 Android 日记与手账 App。把生活写成一页，把照片贴进本子，再把愿意分享的回忆寄给 TA。下一次收到回信时，也许某篇日记下面，已经多了一句「那天我也很开心」。

**📖 日记与自由手账 · 💌 加密文件互传 · 🎞️ 照片、动图与视频 · 🔒 本机私密空间**

Android 8.0+ · 首次只填昵称 · 无云端、无注册账号

## 把小日子，慢慢写成我们的故事

### 📖 今天发生的小事，都有地方安放

认真写一篇长日记，或者只记一句「今天有点想你」。给这一天选个心情，放上照片、GIF 或视频，以后还能按标题、正文和日期找回来。

从第一天写到很久以后，同页没有使用天数限制，也没有本机日记篇数配额。记录能存多少，取决于手机的可用空间。

### ✂️ 不用整整齐齐，也能拼出喜欢的一页

把合照放大一点，把文字斜着贴，再添一枚小贴纸。自由手账支持拖动、缩放、旋转和图层置顶，也能调整文字颜色、字号，画几笔涂鸦，撤销后重新来过。

这里有 **8 种纸张、4 种可编辑模板和 12 枚通用贴纸**。一顿晚饭、一次散步、一次旅行，都可以拥有自己的排版。照片、动图与视频也能放进手账。

### 💌 你写今天，我读到你的生活

两个人各自在自己的手机上记录。准备好分享时，点一下「寄给 TA」，用微信、QQ 等发送加密的 `.couple` 回忆文件；TA 收下并确认后，就能看到这次带来的更新。

在对方的非私密日记或手账下面留句话，下次互传时，这份回应也会一起送达。共同页还可以轮流续写，让同一天留下两个人的视角。

**这是主动交换回忆的方式：对方确认收下文件后才会更新，不提供实时云同步。**

### 🌿 打开 App，像翻开一本熟悉的小本子

奶油纸色搭配鼠尾草、雾粉、雾蓝三种主题，柔和封面、书页线稿和相纸式相册，让记录多一点纸张的温度。

首页能看到在一起的天数、当天记录和最近日记；回忆页把共享的影像与手账收在一起。那些当时随手记下的小事，慢慢就有了时间的形状。

## 两个人，也各自留一点自己的空间

| 空间 | 可以做什么 |
| --- | --- |
| **我的** | 写自己的日记与手账，修改、删除，和 TA 在评论里回应彼此。 |
| **TA 的** | 读 TA 分享的生活、发表评论；正文和手账布局由 TA 自己管理。 |
| **共同** | 两个人都能续写、编辑、评论，或删除共同页。 |
| **私密** | 留给自己的心事，只在本机保存，绝不进入寄给 TA 的 `.couple` 文件。 |

所有非私密日记和手账都可以评论。评论随下一次互传送达；双方各自留下的评论会追加合并，重复收件不会重复显示。

## 从第一声「你好」到第一份回忆

1. **各自写下昵称。** 首次打开点「开始记录」，双方分别拥有独立的本机身份。
2. **关联一次。** 一人生成并复制口令，发给 TA；TA 点「粘贴并加入」。口令请只交给对方。
3. **写好，寄出去。** 点「寄给 TA」选择微信、QQ 等，也可以先保存文件再发送。
4. **收到，确认收下。** 用同页打开收到的 `.couple` 文件，查看预览后点「收下这份回忆」。若聊天应用无法直接打开，先保存，再到同页点「收下 TA 的生活」选择文件。

平时写日记可以离线进行；发送文件所需的连接取决于你们选择的传输工具。照片、视频和评论会随回忆文件一同交换，便签和额外纪念日目前只保存在本机。

## 多拍几张，也装得下这一天

照片、动图和视频导入后会复制到应用内部。GIF 自动播放，视频支持暂停、继续和拖动进度；常见 MP4 更适合互传，具体播放能力取决于手机支持的编码。

「寄给 TA」与「导出数据与影像」都使用流式文件处理，逐个读取媒体并写入磁盘，减少大量影像导出时的内存占用。照片保持原图，相同内容只打包一次；收到回信确认后，已确认的影像无需重复寄送。

单次互传仍受手机空间、协议限制和聊天工具附件大小限制，超大文件目前不会自动拆包。详细限制见下方说明与[本地交换指南](docs/local-exchange-guide.md)。

## 开发与构建

采用 Kotlin、Jetpack Compose、Material 3、ViewModel + StateFlow、Room、Coil 与 AndroidX Biometric。

| 项目 | 版本 |
| --- | --- |
| Kotlin / Room | 2.1.20 / 2.7.1 |
| Android Gradle Plugin / Gradle | 8.11.1 / 8.14.3 |
| 构建环境 | 已验证 JDK 21，最低 JDK 17；Android SDK 36 |
| Android 支持 | 最低 API 26（Android 8.0），目标 API 36 |
| 应用包名 | `app.tongye.diary` |

在 Android Studio 中打开项目并配置 SDK。Windows 可运行：

```powershell
.\build.ps1 -Verify
```

其他系统可运行：

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:streamingLowMemory
```

Windows 脚本会生成 `deliverables/同页-0.2.7.apk` 及 SHA-256。其他电脑请配置 `JAVA_HOME`、`ANDROID_HOME`，并按本机环境生成 `local.properties`；不要提交本机配置、缓存或签名私钥。

已有安装升级时须沿用相同包名与签名，先做好备份，再覆盖安装，保留原有日记和身份。不要通过卸载来升级。

0.2.7 历史验证包含 **48 项单元测试、96 MiB 堆内存下的 8 项流式测试**及 Lint 检查。大量影像测试曾验证 150 MiB 集合与 65 MiB 单图；Android 隔离模拟器曾验证 120 张、120 MiB 的导出场景。这些记录不代表所有实体手机和所有大小的文件均已验证。

## 使用前，了解这些细节

<details>
<summary>展开查看：合并规则、容量、私密保护与备份</summary>

- **共同编辑：** 同一手账的不同元素可以合并；同一元素按较新修改时间处理，时间相同时比较持久身份。正文、背景等属性按较新整页版本处理。如果双方都改了同一篇正文，一方的修改可能被覆盖，当前没有冲突副本。设备时间不准会影响判断。
- **删除：** 自己的记录和共同页都有明确的删除入口与确认。已分享页面的删除标记随下次文件送达，TA 确认收下后才在对方手机生效；私密页删除只影响本机。删除记录暂不清理原始媒体文件，以免影响其他页面的引用。
- **评论：** 每条最多 200 字，每页最多 2000 条，当前没有评论编辑或删除入口。评论不改变正文的冲突时间。
- **单次互传容量：** ZIP 及解压内容最多 8 GiB，每类 JSON 最多 32 MiB，最多 20,000 页记录/删除记录和 5,000 个媒体摘要。这些是单次交换限制，不是本机日记配额。生成和接收都需要额外临时磁盘空间。
- **私密保护：** 可设置 PIN 和受设备支持的生物识别，进入后台后重新锁定；私密页及收藏页防截图。这属于应用内访问保护，Room 数据库内容本身未加密。
- **两种导出：** 寄给 TA 的 `.couple` 文件使用 AES-GCM 认证加密，始终排除私密页。「ZIP 备份」未加密，默认不含私密页，可明确选择加入本人私密页；开启锁后导出私密内容需验证。备份不包含互传口令或 PIN，请妥善保存。
- **备份与恢复：** 当前提供导出，尚未提供 ZIP 备份恢复入口。应用禁用系统云备份与设备迁移，卸载会删除应用数据。
- **尚未提供：** 近距离自动发现、Wi-Fi Direct、拍摄、剪辑、转码、自定义图片贴纸、图片去背景、字体切换、未来信与 PDF 回忆册。
